Your Shortcut connection
Build the first shortcut
  1. Open Shortcuts, tap +, add a URL action, and paste the copied URL.
  2. Add Get Contents of URL. Set Method to POST and Request Body to JSON.
  3. Add these JSON fields: deviceId = your copied ID, token = your copied key, and command = home.
  4. Name it Newline Home. Duplicate it five times and change only the command value.
Home → home
Vivi → vivi
Freeze → freeze
Volume − → volDown
Mute → mute
Volume + → volUp
The key can only send those six commands to this classroom. It cannot pair phones, change settings, reveal the laptop secret, or control another classroom.
