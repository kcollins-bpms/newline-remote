Build Newline Home
  1. Tap Copy URL next to Home.
  2. Open Shortcuts, create a new shortcut, add a URL action, and paste.
  3. Add Get Contents of URL underneath it and set Method to POST. No body fields are needed; if Request Body appears, leave it empty.
  4. Name it Newline Home and run it. That is the entire shortcut.
  5. Duplicate it for the other five controls and replace only the URL with the matching copied URL above.
Each URL contains a random 256-bit credential bound to this classroom, this paired phone, and exactly one approved command. Revoking the links disables all six immediately.
